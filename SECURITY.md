# Security

This is a personal side project without a formal security disclosure
process or response commitment.

If you think you have found a security or privacy issue, please open a
GitHub issue. Useful reports include bypasses, regressions, missing
threat-model cases, or documentation that overstates what the profile
protects against.

For scope, design rationale, and known limits, see [README.md](README.md)
and [HISTORY.md](HISTORY.md).
